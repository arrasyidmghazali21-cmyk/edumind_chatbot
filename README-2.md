# 🎓 EduMind — AI Learning Assistant Chatbot

Final Project — LLM-Based Tools and Gemini API Integration for Data Scientists
**Hacktiv8**

---

## 📌 Use Case
**Education Bot** — Asisten belajar AI yang membantu pengguna memahami berbagai mata pelajaran menggunakan bahasa Indonesia yang santai dan mudah dipahami.

## ✨ Fitur
- 🤖 Powered by **Google Gemini 1.5 Flash**
- 💬 Percakapan multi-turn dengan memori konteks
- 📚 7 topik mata pelajaran (Umum, Matematika, Pemrograman, Sains, Sejarah, Bahasa Inggris, Ekonomi)
- 🎨 UI modern dengan dark theme
- ⚡ Single-file HTML — tidak perlu instalasi apapun

## 🛠️ Parameter Kreatif
| Parameter | Nilai |
|-----------|-------|
| Gaya Bahasa | Santai & informatif (Bahasa Indonesia) |
| Domain | Edukasi umum (multi-subject) |
| Temperature | 0.7 |
| Max Output Tokens | 1500 |
| Memory | Conversation history (multi-turn) |
| Model | gemini-2.0-flash |

## 🚀 Cara Menjalankan

### Option 1 — Buka Langsung
1. Download file `index.html`
2. Buka di browser (Chrome/Firefox/Edge)
3. Masukkan [Gemini API Key](https://aistudio.google.com) kamu
4. Mulai chat!

### Option 2 — GitHub Pages
Aktifkan GitHub Pages dari **Settings → Pages → Deploy from branch (main)**

## 🔑 Mendapatkan API Key
1. Buka [Google AI Studio](https://aistudio.google.com)
2. Klik **Get API Key**
3. Buat project baru → copy API key
4. Paste ke kolom API key di aplikasi
